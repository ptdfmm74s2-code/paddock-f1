# Paddock F1

Jeu de Formule 1 dans le navigateur : manager au mur des stands ou pilote, en solo ou à deux (un pilote + un ingénieur), saison 2026 avec les vrais circuits.

Pour jouer : https://ptdfmm74s2-code.github.io/paddock-f1/

Sur iPad : ouvrir le lien dans Safari, puis Partager → Sur l'écran d'accueil.

Tracés des circuits : bacinger/f1-circuits (licence MIT, © Tomislav Bacinger). Jeu de fan non officiel, sans lien avec la Formule 1, la FIA ou les écuries.
